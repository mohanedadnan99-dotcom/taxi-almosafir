# Taxi Almosafir

المستودع الرئيسي لموقع **تكسي المسافر**.

## Workflow
- GitHub هو المصدر الأساسي للكود.
- Vercel يستخدم للنشر التجريبي والنهائي.
- أي تعديل جديد يفضل أن يبدأ من هذا المستودع حتى تبقى النسخ مرتبة ومحفوظة.

## Current prototype
نسخة أولية لحجز نقل المطار تشمل:
- اختيار السيارة
- مغادرة / استقبال
- الكرخ / الرصافة
- بيانات الحجز المبسطة

ربط Telegram سيتم إضافته بعد اعتماد تجربة الحجز والتصميم.
