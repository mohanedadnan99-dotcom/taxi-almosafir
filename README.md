# Taxi Almosafir — تكسي المسافر

المستودع الرئيسي والوحيد لمشروع **تكسي المسافر**.

## Source of truth
- GitHub هو المصدر الأساسي للكود.
- `main` = النسخة المعتمدة والجاهزة للإنتاج.
- `preview` = التعديلات والتجارب قبل الاعتماد.
- Vercel يستخدم فقط للنشر والمعاينة، وليس لحفظ نسخ منفصلة من المشروع.

## Current booking flow
1. اختيار السيارة.
2. اختيار مغادرة أو استقبال.
3. اختيار الكرخ أو الرصافة.
4. إدخال اسم المسافر ورقم الهاتف.
5. تحديد عدد الحقائب والتاريخ والوقت.
6. إضافة ملاحظات اختيارية.
7. تأكيد الحجز.

## Planned integrations
- إرسال الطلب مباشرة إلى Telegram.
- إنشاء رقم حجز تلقائي.
- حفظ الحجوزات لأغراض الإحصاء واحتساب نسبة المشروع.
- ربط Vercel Git Integration حتى يتم النشر تلقائياً من GitHub.

## Security
لا يتم حفظ Telegram Bot Token أو أي مفاتيح سرية داخل GitHub. توضع الأسرار فقط داخل Vercel Environment Variables.
